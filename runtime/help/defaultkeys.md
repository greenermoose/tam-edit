# Default keybindings

| Key | Action |
| --- | --- |
| Ctrl+G | Show current keybindings or prompt guidance |
| Ctrl+E | Search and run named actions or type an editor command |
| Alt+E | Open the command prompt |
| Ctrl+N / Ctrl+O | New untitled tab / open a file |
| Ctrl+S / Ctrl+D / Ctrl+Q | Save / close active view / quit |
| Ctrl+U / Ctrl+L | Reload active file / redraw screen |
| Ctrl+F / Alt+F / Ctrl+R | Find / find literal text / replace |
| Alt+J / Alt+Shift+J | Find next / previous match |
| Alt+T / Alt+Shift+T | Next / previous tab |
| Ctrl+A | Select all |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste |
| Ctrl+K | Delete the active line |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+Left / Ctrl+Right | Move by word |
| Ctrl+Home / Ctrl+End | Move to beginning / end of buffer |
| Shift+navigation | Extend selection |
| Ctrl+Backspace / Ctrl+Delete | Delete word left / right |
| Escape | Cancel the prompt, help view, or selection |

## Linux console and compact keyboards

Alt+, and Alt+. move by word. Alt+< and Alt+> move to the beginning
and end of the buffer. Alt+Backspace and Alt+D delete words. Alt+M
sets a selection anchor, then movement extends the selection. Press
Alt+M again or Escape to clear it.
